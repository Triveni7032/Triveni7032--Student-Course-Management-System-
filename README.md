# Student Course Management System

A Python-based Student Course Management System that uses JSON for storing and managing student information.

## Features

- View student details
- Search students by ID
- Add new students
- Update student marks
- Find high-scoring students
- Store data permanently using JSON

## Technologies Used

- Python
- JSON
- Lists
- Dictionaries
- Functions
- File Handling
- Exception Handling
